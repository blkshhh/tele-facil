# Tele Fácil · actualizaciones

Archivos que la app **Tele Fácil** (Android TV) se baja sola para mantenerse al día sin reinstalarla:

- `canales.json` — la parrilla de canales (todos públicos y gratuitos: TDTChannels, Pluto TV, Samsung TV Plus, Rakuten TV,
  Plex, webs oficiales de las cadenas).
- `web/canal.js` y `web/config.json` — ajustes para las webs oficiales de Atresmedia y Mediaset.
- `version.json` — última versión de la app; el APK va en [Releases](../../releases). Android solo lo instala si va firmado
  con la misma clave que la app ya instalada.

Aquí solo hay estos archivos: ni datos de usuarios ni de clientes.
